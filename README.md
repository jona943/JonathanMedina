## 📂 Estructura del Proyecto

El sitio es una **Single Page Application (SPA)** construida con tecnologías web estándar para maximizar la velocidad y eficiencia:

- `index.html`: Punto de entrada único que contiene todas las secciones (Sobre mí, Experiencia, Portafolio, Galería).
- `assets/css/`: Estilos modernos con diseño responsive y animaciones.
- `assets/js/`: Lógica de interactividad y navegación ágil.
- `assets/img/`: Directorio organizado de evidencias, proyectos y perfil.
